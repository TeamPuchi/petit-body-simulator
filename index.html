Petit Body Simulator

ぷちの体（M5Stack CoreS3）の画面と、タップ・なぞる・長押しの動きを、ブラウザで試すもの。ファーム m5_petit_cloud cloud-0.2.0 ／ 設定ページ Ver1.0 の数値どおりに描いています。実機の撮影ではありません。

いま: 起動中 長押し
さわり方（マウスでも指でも）
  • 起動中に画面を長押し → 数字が 0 になったら離す → 設定モード（QR）。右に「スマホ」が出ます
  • いつもの顔: タップ＝その方を見る／横になぞる＝なでる（ハート）／1 秒に 3 回以上タップ＝こちょこちょ（まばたき）
  • 下端から上へなぞる → おと・ひかり・ながもち → さらに上へ → いま だれ → さらに上へ → ぷちに おねがい → さらに上へ → 顔
  • 上端から下へなぞる → ぷちに おねがい（直行）。各ページで下へなぞると前へ、おと画面で下へ → 顔
  • 何もないところを 3 回タップ → 顔に戻る。20 秒さわらないと閉じる。おやすみ中は 3 回タップで起きる
